# ChainArgos frontend (platform, ui-design-system, documentation-portal)

## What it is
- `ui-design-system`: Bun workspace `frontend/packages/` — `contracts` (types, zod), `ui` (generic controls, tokens), `platform-ui` (generic blocks), `domain-ui` (ChainArgos/blockchain compositions), `styles` (Zyzz token contract).
- `platform`: the ChainArgos SPA (`frontend/platform`) plus the redesign record in `redesign/`.
- `documentation-portal`: Fumadocs site (`frontend/docs`) with all `.mdx`, the design-system gallery, and a LikeC4 model.
- Platform and docs consume `@chainargos/*` as `workspace:*` links to the sibling `ui-design-system` checkout (repos must sit side by side). Edit design-system source there; there is no release or version bump. Install order: ui-design-system → documentation-portal → platform.

## Stack
TypeScript 7 native `tsc` with the strictest flags (`exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`, `noPropertyAccessFromIndexSignature`, `erasableSyntaxOnly`, `verbatimModuleSyntax`); Bun only (no Node); React 19; Vite 8; TanStack Start/Router/Query/Form/Table/Virtual; Base UI is the only primitive library (ReUI/shadcn are references only); Zyzz styling with `@chainargos/styles` tokens (Tailwind being removed — add none); React Flow, CodeMirror 6, zod 4, lucide-react; oxlint type-aware (`--deny-warnings`, react + jsx-a11y) and oxfmt; Playwright + axe; Fumadocs + `@fumadocs/story` (no Storybook).

## Gates
- Every repo: `mise run install` (needs `NPM_TOKEN`), `hk check --all`.
- ui-design-system: per package `bun --bun run check`; in `frontend/scripts`: `bun --bun run check`, `bun --bun run gates`.
- platform: `mise run check`; in `frontend/platform`: `bun --bun run check`, `bun --bun run build:check`, `bun --bun run test:e2e`.
- documentation-portal: in `frontend/docs`: `bun --bun run ci`, `bun --bun run check:mdx`.

## Rules that change how agents work
- Platform is SPA-only: no SSR, server functions, server loaders or SSR prefetch; verify with `bun --bun run dev` / `build`, never an SSR smoke. Loaders use `queryClient.query()` + `useSuspenseQuery` (checked 2026-11-01: 28 files in `frontend/platform/src`, none use `ensureQueryData`).
- Types: discriminated unions, zod at boundaries, branded ids, `satisfies never`, `Result` over throws; no `any`, `as`, `!`. No comments except runtime pragmas; no `@deprecated`.
- View / data / action split; views never import sample data.
- `ui` and `platform-ui` stay domain-free (names, props, CSS variables, copy); domain material goes in `domain-ui`. New components follow `execution/architecture.md` §8 and get an explicit subpath export.
- Styling imports `style`/`variants` only from `@chainargos/styles/zyzz.config`, never `zyzz/runtime`. Theme via `data-theme`, key `ca-theme`.
- No unit tests (functional/e2e only). No stories or tests unless asked.
- Dependency choice: current maintained line, newest stable (or newest prerelease if none), exact pins, singletons identical across the three repos via `workspaces.catalog`, cite sources with date, record a DEC in `platform/redesign/decisions.md`.
- Visual review: screenshots at 1440px and 390px, light and dark, side by side with `redesign/drafts/0N-*.html`; critical/high findings must be fixed. a11y: WCAG 2.2 AA; axe fails on serious/critical (DEC-038 temporarily disables `label-content-name-mismatch`).
- Only the docs writer edits `.mdx`; `generated: true` pages are regenerated, never hand-edited. Docs rules: `frontend/docs/content/docs/contributing/documentation-rules.mdx`, `design-system/family-page-guide.mdx`.
