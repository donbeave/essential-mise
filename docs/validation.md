Validation targets Apple Silicon macOS **27.2 (26B123)**, mise **2026.10.23 macos-arm64**, Tart **2.41.1**, and Cua Driver **0.38.0**. The host has 64 GB RAM. Test guests have 4 CPUs, 8192 MB RAM, and a 100 GB disk.

Disposable guests include the earlier release/final/Amp guests and the new `essential-mise-test-cold`, `essential-mise-test-audit`, and `essential-mise-test-cask`. All are stopped after evidence collection. All guest accounts and data are synthetic. No application under test runs on the physical host, no host directory is shared, clipboard sharing is disabled, and NAT is not treated as complete security isolation. SIP, Gatekeeper, and normal TCC behavior remain enabled.

Exact source revisions, fixture checksums, mise versions, guest OS/build values, commands, logs, exit codes, screenshots, and artifact hashes are preserved in [validation evidence](validation-evidence/). The [complete earlier bundle](validation-evidence/43e23cfda1c22f57476565d2e08b4d0d6431ff92/SUMMARY.md) and [focused Java/Claude bundle](validation-evidence/e81fe5902edf6f04e3925cae8f128ab50e0216da/SUMMARY.md) are supplemented by the [configuration-safety and cold-install bundle](validation-evidence/03ede6d37cafc6f19939225c01e185a2cff499b3/SUMMARY.md). ## Compatibility exceptions and management limits

Native mise remains the default. Five AI package exceptions were explicitly approved; Surge is the sixth under the user's conditional real-Homebrew fallback for demonstrated current-mise failures. Exact errors and evidence are in [Homebrew exceptions](homebrew-exceptions.md).

These hooks are not declarative package resources. They ensure presence only when absent and run health checks on every apply; they do not upgrade installed-but-outdated packages, as the real Amp CLI fixture proves. Native status/upgrades/prune do not manage them. The observed prune dry run offered to remove working Amp CLI, FFF, and OMP hook installations; applying a broad native formula prune is prohibited while they must remain installed. Review candidates and perform separately approved, explicit Homebrew cleanup instead. Upgrade and removal owners are documented individually. Deselecting a module does not uninstall these packages, and no automatic ownership transfer is allowed.

The Claude status-line script is a separate approved exception and remains byte-for-byte unchanged. Its displayed absolute usage is input-token usage, matching the documented `used_percentage` formula; output tokens are intentionally not added. A failed verifier rerun removes old zero-exit artifacts and writes FAIL; a later recovery passes independently.

## Accepted scoped-v1 limitations

- **App Store:** 21 MAS applications are still missing, including Apple Configurator (`mas:1037126344`). Signed-out metadata and the sign-in/cancel flow are verified. Signed-in installation, purchases/claims, and reruns are explicitly accepted as manual, unverified v1 boundaries because no authorized synthetic Apple Account is available; personal accounts are not permitted. The standard workstation is not fully release-tested.
- **Amp Desktop GUI:** `1.0,998` installs with a valid signature and an executable byte-identical to the official DMG. Independent guests reproduce a main-thread `_dyld_start` stall with no window. The project explicitly retains automatic package installation for inventory completeness and accepts this known nonfunctional-GUI limitation on macOS 27.2. GUI setup is **MANUAL / DROP**; no signing or security bypass is introduced.
- **Authenticated AI behavior:** OMP provider routes, authenticated models, and runtime instruction loading are explicitly accepted manual verification boundaries. Authenticated interactive Claude status-line rendering is likewise an accepted manual verification boundary; no success is claimed.
- **Application onboarding:** accounts, licenses, paid purchases, privacy consents, privileged extensions, browser/VPN profiles, and app-specific setup remain manual as documented.
- **Preference behavior and delayed reversal:** stored values and unrelated-member preservation are verified, but every affected UI behavior and delayed selective reversal is a manual boundary. Exact full-domain snapshots support immediate rollback; no delayed import is presented as safe.

These are deliberate scoped-v1 decisions, not untriaged product questions or evidence of working behavior. The repository remains PRE-RELEASE because unrestricted public-release approval is separate and the complete standard workstation has not passed an end-to-end release gate. A successful package installation, dry run, CLI version, or screenshot alone is not release approval.
